# 導入と動作確認

> GitHub Pages への公開手順は **README-deploy.md** を見てください。

## 1. 動かす

ZIP を展開して、そのフォルダで:

```bash
npm install
npm run dev
```

`http://localhost:3000` を開くと、すぐイントロが始まります。

> `npm install` はネットワークが必要です。フォント（Noto Sans JP）も
> 初回ビルド時に Google Fonts から取得します。

## 2. テストする

```bash
npx vitest run
```

22 件通れば OK です。問題データの解き筋そのものも検証しています。

> テストは Node の環境で走ります（ブラウザ環境の再現は使いません）。
> Node 20 以上であれば動きます。

## 3. 動作確認の順番（1 つずつ確かめる）

1. 開くとすぐイントロが出て、トヨタくんの絵が表示される
2. 第 1 問に **さかえく** → 正解、キーワード枠が 1 つ緑になる
3. **サカエク** **栄区** **さかえ区** でも正解になる（表記ゆれの確認）
4. わざと間違える → セリフが変わる、画面は進まない
5. ヒントを 1 つ開く → **ページをリロードしても** ヒントが開いたまま、進捗も残る（保存の確認）
6. ヒントを 3 つまで開ける。3 つ開くと「ぜんぶ出したよ」になる
7. 🔊 読み上げボタンで問題が読まれる（PC の Chrome / iOS Safari で確認推奨）
8. 第 2 問 **あき**（「たかはしあき」だと専用コメントが出る）、第 3 問 **はな**
9. 最終問題 **きく** → この時点では答えを明かさない。「結果を見る」で星・称号・「なぜ『きく』？」の解説が出る
10. ヒントを 1 つも使わずに通すと星 3、5 回以上使うと星 1
11. 「もう一度あそぶ」で全部リセットされる

## 問題の追加・変更のしかた

`/data/puzzles.ts` **だけ**を編集します。ほかのファイルは触りません。

```ts
{
  id: "q4",                    // 重複させない（進捗保存のキー）
  label: "第4問",
  title: "問題のタイトル",
  intro: "トヨタくんのセリフ",
  question: "問題文",
  visual: { kind: "fraction-list", items: [...] },  // 図（省略可）
  placeholder: "ひらがなで答えてね",
  hints: ["ゆるいヒント", "ふつうのヒント", "ほぼ答え"],  // 必ず3つ
  answers: ["ひらがな", "漢字", "カタカナ"],              // 表記ゆれを列挙
  keyword: "キーワード",
  success: "正解時のセリフ",
  speech: "読み上げ用の文（記号を言葉に置きかえる）",
}
```

守ること:

- **`hints` は必ず 3 つ**（テストで本数を検証しています）
- **`answers` に漢字表記も入れる**。判定は「カタカナ→ひらがな」は自動でやりますが、
  漢字→読みの変換はできません
- **`id` を重複させない**。進捗保存とヒント数の記録キーになっています
- **`speech` は記号を言葉に**。「↑」「3/4」はそのままだと読み上げられません

追加したら `npx vitest run` を回すと、データの不備（ヒント数、ID 重複、
キーワードが正解に含まれていない等）を自動で見つけてくれます。

## 音声について

ブラウザ標準の Web Speech API を使っています。サーバーも API キーも不要です。

- **自動読み上げはしません**。iOS Safari がユーザー操作なしでは発話しないためです
- 端末に日本語の音声が入っていない場合、🔊 ボタン自体が出ません
- 読み上げ文面は各問題の `speech`、正解時は `successSpeech` に書きます
- **漢字はかなで書いてください**。読み上げエンジンは読みを取りちがえます
  （「表」が「おもて」と読まれた実例があります）。読みが割れる語はテストで検出します

## 各問題の解き筋（原稿より）

**第1問** — 矢印は「漢字のどの位置にカタカナが隠れているか」を指す

| 漢字 | 矢印 | 位置 | カタカナ |
|---|---|---|---|
| 花 | ↑ | 上 | 艹 → サ |
| 加 | ← | 左 | 力 → カ |
| 功 | ← | 左 | 工 → エ |
| 久 | ↖ | 左上 | ク |

→ サカエク（栄区）

**第2問** — 「むしめがね」「むしば」の共通部分「むし」を無視し、
残った め・が・ね・ば をグリッドから消す → たかはしあき →
ヒント「季節」で **あき**

**第3問** — 分母は文字数、分子は何文字めか。
よこはま 3/4 → は、地区センター 0 → とらない、なぞ 1/2 → な → **はな**

**最終問題** — さかえく・あき・はな → **きく（菊）**

> 第2問で「たかはしあき」と入力した場合は、不正解ではなく
> 「そこまでは合ってる」という専用コメントが出ます。
